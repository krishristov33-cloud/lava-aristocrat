# LAVA ARISTOCRAT NIGHT

Playable prototype: https://krishristov33-cloud.github.io/lava-aristocrat/

One self-contained page (built from bozh-ops-58/forge-html-games, branch lava-aristocrat-v1, lava-aristocrat v11). Plays in landscape and portrait, desktop and mobile.

v11: mobile performance + memory (smoother bursts, ~1/3 less memory, fixes phone crashes entering free spins / collecting; desktop unchanged). 5x3 243-ways cascades, lava lamp eruptions with galaxy-map multipliers, Floor Wipe, 8 free spins with the Trophy lamp, animated Rynax (9 sequences), ember particles + glowing lava heat on background, foreground and shaft, smaller royals, "Subspace Echo" theme. RTP 96.3%, max win 20,000x.
